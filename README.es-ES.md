

# Chatbot basado en GPT a partir de un folleto de producto

### Fuente de datos: [Folleto de la Mercedes Benz Clase A Limousine](https://raw.githubusercontent.com/pythongasm/cdn/b591806117badeb7b95e85af60302aca8b07727e/The%20Mercedes-Benz%20A-Class%20Limousine.pdf)

### [Tutorial](https://www.pythongasm.com/build-gpt-powered-chatbots-around-enterprise-data-with-python)

https://github.com/adarshpunj/gpt-chatbot-example/assets/30762976/58d7c3e5-6e09-4460-9785-b4d5567d3482

## Ejecutar 

- Instalar las dependencias
  ```
  pip install -r requirements.txt
  ```
- Ir al directorio del backend y ejecutar:
  ```
  uvicorn main:app --port 8080 --reload
  ```
## Preguntar
- ¿Cuál es la velocidad máxima?
- ¿Puedo conectar mi iPhone?
- ¿Es compatible con Alexa?
- ¿Cuál es el tamaño de las llantas de aleación?
